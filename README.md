🧮 Calculator
A simple and functional calculator web app that allows users to perform basic arithmetic calculations.
This project provides an easy-to-use interface for basic mathematical operations like addition, subtraction, multiplication, and division.

🚀 Features
Basic Arithmetic Operations: Perform addition, subtraction, multiplication, and division.
Clear and Equal Buttons: Reset the display with "C" and calculate the result with "=".
Responsive Interface: A clean and easy-to-use layout for both desktop and mobile devices.

🎮 How to Use
Open the calculator in your browser.
Enter numbers and select operators by clicking on the respective buttons.
Press the "=" button to calculate the result.
Press the "C" button to clear the display.

🛠️ Technologies Used
HTML – Structure of the calculator, including buttons and display.
CSS – Design and layout for the calculator buttons and screen.
JavaScript – Logic for performing arithmetic operations and updating the display.
